# Job Interview Course — build files
- Lessons: L1 ... L5 (open `index.html` in this folder, then pick a lesson).
- Source: `_build/lessons/L1.py ...` (slides), `_build/shared/` (engine, styles), `_build/lib.py` (exercise builders).
- Rebuild everything: `cd _build && python3 build.py` (or `python3 build.py L3` for one lesson).
- Course URL for the "Save Notes" PDF is set in `_build/build.py` (BASEURL). Change it when you know where the course will be hosted.
